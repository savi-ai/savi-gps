Frontend Architecture

App Router coordinates repo selection, cache probe (REST), SSE streaming phases and panel hydration (glossary, advisories, modernization insights).

  • Cache signals: shows a "Stale" badge when TTL expired but a row exists.
  • Invalidate control: one-click invalidate triggers regeneration via server action.
  • Telemetry: emits invalidate_diagram event on invalidate click (client-side).

End-to-End Repo → Diagram Flow

  1. User selects repo & model.
  2. UI parallel: tree fetch, ingest status, cache probe.
  3. Ingest: clone → enumerate → parse → graph upsert.
  4. Prepare: summaries, embeddings, processes, advisories.
  5. Generate: SSE phases explanation → mapping → diagram with cost telemetry.
  6. Cache: sanitized diagram + explanation persisted.
  7. Replay: direct REST hit if version + TTL valid.

Caching Strategies

  • Content Hash Idempotency: avoids duplicate ingest and summaries.
  • Prompt Version Hash: instruction drift triggers regeneration.
  • TTL Expiry: optional freshness; NULL = infinite.
  • Fast Path: REST GET before any generation work.

Retrieval Algorithm (Pseudo)
function fetchDiagram(user, repo, instructions) {
  const hash = sha1(instructions)
  const row = SELECT * FROM diagram_cache
             WHERE username=user AND repo=repo AND instruction_hash=hash
  if(!row) return MISS
  if(row.expires_at && row.expires_at < now()) return EXPIRED // UI shows "Stale" badge
  asyncUpdateLastAccessed(row)
  return HIT(row)
}

function invalidate(user, repo, instructions) {
  const hash = sha1(instructions)
  DELETE FROM diagram_cache WHERE username=user AND repo=repo AND instruction_hash=hash
  emitTelemetry('invalidate_diagram', { user, repo })
}

function regenerate(user, repo, payload) {
  const sanitized = sanitizeMermaid(payload.diagram)
  UPSERT sanitized + metadata (unique by username, repo, instruction_hash)
}

Troubleshooting

  • Mermaid parse → sanitize & retry
  • Stream stall >30s → provider timeout
  • Unexpected miss → check key + hash
  • Duplicate key on upsert → run DB migrations; ensure index sdc_user_repo_instr_uq exists

Conclusion

Composite uniqueness + explicit version hashing, UI stale signals, and invalidate control deliver low-latency, correct, and observable replays.
